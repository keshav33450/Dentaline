MODEL 2 - TOOTH TYPE (intraoral, view-robust)     TRAINED 05-10-2026 on Kaggle (YOLO11s)

Detects each tooth and labels it:  incisor / canine / premolar / molar
Works across frontal AND occlusal (upper/lower) intraoral photos.

Test accuracy (134 images, 2,243 teeth):
   Overall  mAP50 94.6   mAP50-95 66.6
   Per view: frontal 94.9 | upper 94.7 | lower 94.5
   Per class: incisor 97.3 | canine 95.1 | premolar 94.4 | molar 91.5

HOW TO RUN
   1) one-click : ANALYZE_TEST_IMAGES.bat   (put photos in test_images\)
        -> result .jpg + .json  in  test_images\results
   2) one photo : drag it onto  code\windows\analyze_image.bat
   3) local API : code\windows\run_api.bat   ->  http://localhost:8002

Data: DentalMate6v Front/Upper/Lower intraoral datasets (CC BY 4.0), FDI remapped to 4 types.
Research prototype - not a diagnosis.
